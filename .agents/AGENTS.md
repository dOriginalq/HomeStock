# Workspace Rules for HomeStock

## Codebase Analysis & Knowledge Graph
- Always use **graphify** (`graphify-out/graph.json` / `/graphify query`) for any question about codebase architecture, file relationships, module boundaries, or project structure.

## Git & Branch Management
- Always work on and push to the **`lal`** branch.
- Never commit or push directly to `main`, `master`, or any other branch. All changes and pushes MUST target the `lal` branch.
